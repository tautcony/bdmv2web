# Spec Delta

## Purpose

为离线 BDMV 转换和浏览器运行提供可验证的建立共享契约与安全基础能力，明确输入、输出、错误及对下游的可观察行为。

## ADDED Requirements

### Requirement: 版本化数据与精确时间

系统 SHALL 为 Disc IR、资产引用和诊断提供版本化、可校验的共享数据契约，保留来源位置与原始标识。

#### Scenario: 序列化超过安全整数范围的 90 kHz 时间并重新装载

- **WHEN** 序列化超过安全整数范围的 90 kHz 时间并重新装载
- **THEN** 时间以十进制字符串持久化并无损还原，版本不兼容时明确报错

### Requirement: 导航类型与扩展

系统 SHALL 区分 HDMV 和 BD-J 入口，并为导航后端提供独立接入契约。

#### Scenario: 处理 BD-J 类型入口

- **WHEN** 处理 BD-J 类型入口
- **THEN** 保留其标识并报告不支持，不执行 Java 或伪造菜单

### Requirement: 安全读取与诊断

系统 SHALL 有界读取输入并用结构化诊断说明错误位置及可恢复性。

#### Scenario: 输入截断、越界或声明超大长度

- **WHEN** 输入截断、越界或声明超大长度
- **THEN** 读取安全终止并报告来源、偏移和错误代码
