# OpenSpec change 工件

当前行为与验收口径见 [`../specs/`](../specs/)。本目录保存 change 工件和实施过程记录。

## 目录布局

| 位置 | 内容 |
| --- | --- |
| `<change>/` | 活动 change 的 `proposal.md`、`design.md`、`specs/`、`tasks.md` |
| `archive/` | 已完成 change 的冻结归档 |
| 顶层 `.md` | 跨 change 的实施顺序、范围调整与评审记录 |

## 顶层文件

| 文件 | 记录内容 | 基准 |
| --- | --- | --- |
| `DEPENDENCIES.md` | 首期 change 间的实施依赖与顺序 | 2026-11-04 架构方案 |
| `IMPLEMENTATION_BASELINE.md` | 模块所有权与跨 change 交接约定 | 2026-11-07 实施基线 |
| `REVIEW_BACKLOG.md` | 评审遗留问题及其触发条件 | 2026-11-04 评审 |
| `scope-changes.md` | 活动 change 的验收范围调整 | 2026-11-09 |
| `task-disposition-index.md` | 未勾选任务的逐项处置索引 | 2026-11-09 审计 |
