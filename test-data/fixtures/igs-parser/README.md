# Real IGS composition sample

`ics-menu-disc14.bin` is a 6,129-byte upstream ICS fixture. Its source and MIT license are included here. The parser test wraps the body in a minimal segment and END marker, then checks its 1920×1080 composition and four button pages.

`synthetic-single-object.m2ts` is the packetized single-object pixel fixture generated by `packages/igs/test/fixtures.ts::syntheticReferenceClip()`, with each IGS segment in its own PES. The IGS reference comparison uses it to compare the independently exported RGBA element; the parser test checks that this byte fixture remains aligned with its builder.
